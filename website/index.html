Features

Built for reading a busy machine at a glance

A stable process tree

Parents and children stay where they are while metrics update, so you can follow a process without it jumping around.

Tree lock

Freeze the order while you investigate. Values keep refreshing and rows stay put.

Search in place

Type to highlight matching rows and jump between results without hiding the rest of the tree.

Live metrics and history

CPU, memory, network, and storage per process and per subtree, with history charts you can hover for exact values.

A detailed inspector

Open files, sockets, threads, and security details, with clear hints when the system restricts access.

Snapshots

Capture the tree, name it, export it, and open it again later to compare with what is running now.

Platforms

Native builds for your desktop

One app with the same behavior everywhere. Each build is made natively on its platform from the same release.

macOSSigned, notarized DMG for Apple silicon with automatic updates. LinuxRPM, DEB, AppImage, and a portable tarball, with per-process network telemetry. WindowsInstaller and portable ZIP for 64-bit Windows.

How Mimameidr is built

A Rust core

Process enumeration, metrics, and actions run in a native Rust engine, so the interface stays responsive.

Local only

Everything stays on your machine. No accounts, and no analytics.
